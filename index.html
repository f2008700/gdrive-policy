Privacy Policy for Drive Folder Size Extension

Last updated: October 28, 2025

Information Collection and Use

The Drive Folder Size extension requires access to your Google Drive files and folders for the sole purpose of calculating folder sizes. We only access metadata (file names, sizes, and folder structure) and do not access, store, or transmit the actual content of your files.

Data Storage

All calculations are performed locally in your browser. We use Chrome's storage API to cache folder size calculations temporarily to improve performance. This data is stored locally on your device and is not transmitted to any external servers.

Google Drive API Usage

We use the Google Drive API with read-only access to metadata. The extension requires the following permission scope: https://www.googleapis.com/auth/drive.metadata.readonly

Data Sharing

We do not collect, store, or share any personal information or file data with third parties.
